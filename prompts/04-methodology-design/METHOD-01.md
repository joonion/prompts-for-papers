# METHOD-01. 연구 질문과 방법론 적합성 비교

| 항목 | 내용 |
|---|---|
| 작업 | 가능한 연구 방법을 질문·근거·제약에 따라 비교 |
| 태그 | `방법론`, `설계 선택`, `타당도` |
| 입력 유형 | 연구 질문, 이론, 자료 접근성, 후보 방법, 현실적 제약 |
| 출력 형식 | 방법 비교표, 추천안, 타당도 위협 목록 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

선호하는 기법을 먼저 정하지 않고 연구 질문에 가장 적합한 설계와 방법을 비교한다.

### 필요한 입력

- `[연구 질문과 목적]`
- `[이론적 또는 개념적 틀]`
- `[접근 가능한 대상·자료·현장]`
- `[고려 중인 연구 방법]`
- `[기간, 예산, 기술과 윤리적 제약]`

### 프롬프트

```text
다음 연구 질문에 답하기 위한 방법론 대안을 비교하세요.

[연구 질문과 목적]
[이론적 또는 개념적 틀]
[접근 가능한 대상·자료·현장]
[고려 중인 연구 방법]
[기간, 예산, 기술과 윤리적 제약]

질문이 요구하는 지식의 유형을 먼저 설명한 뒤, 최소 3개의 가능한 설계를 비교하세요.
비교표에는 질문과의 적합성, 필요한 자료, 분석 단위, 장점, 한계, 주요 타당도 위협,
윤리적 쟁점, 자원 요구와 가능한 결론의 범위를 포함하세요.

가장 적합한 설계와 현실적 대안을 각각 1개 추천하고 선택 조건을 설명하세요. 설계가
허용하지 않는 인과·일반화 주장을 명시하세요. 제공되지 않은 표본 크기, 효과 크기나
현장 접근 가능성을 임의로 가정하지 말고 "확인 필요"로 표시하세요. 마지막에는
선택 전에 연구자가 답해야 할 핵심 질문을 제시하세요.
```

### 제한 조건

- 최신 유행이나 도구 친숙도만으로 방법을 추천하지 않는다.
- 질적·양적 방법을 우열 관계로 단순화하지 않는다.
- 설계가 뒷받침하지 못하는 결론 범위를 명시한다.

### 검증 체크리스트

- [ ] 방법 선택이 연구 질문의 동사와 지식 목적에 연결되는가
- [ ] 타당도, 윤리와 실행 가능성이 함께 비교되었는가
- [ ] 추천안과 현실적 대안의 선택 조건이 분명한가
- [ ] 미확인 가정이 명시되었는가
