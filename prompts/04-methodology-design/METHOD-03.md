# METHOD-03. 연구 프로토콜의 내부 일관성 점검

| 항목 | 내용 |
|---|---|
| 작업 | 질문·설계·측정·분석·윤리 계획의 연결 관계 검토 |
| 태그 | `프로토콜`, `혼합방법`, `재현성`, `데이터 관리` |
| 입력 유형 | 연구계획서 또는 프로토콜 초안 |
| 출력 형식 | 정렬 행렬, 불일치 목록, 수정 우선순위 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

연구계획서의 각 요소가 같은 연구 질문에 답하도록 정렬되어 있는지 투고나 심의 전에 점검한다.

### 필요한 입력

- `[연구 목적과 질문·가설]`
- `[연구 설계와 대상]`
- `[개념·변수·측정 도구]`
- `[자료수집과 분석 계획]`
- `[질적·양적 자료의 통합 계획—해당하는 경우]`
- `[윤리·보안·데이터 관리 계획]`

### 프롬프트

```text
아래 연구 프로토콜의 내부 일관성을 검토하세요.

[연구 목적과 질문·가설]
[연구 설계와 대상]
[개념·변수·측정 도구]
[자료수집과 분석 계획]
[질적·양적 자료의 통합 계획—해당하는 경우]
[윤리·보안·데이터 관리 계획]

연구 질문별로 필요한 개념, 자료, 측정, 분석, 예상 출력과 가능한 결론을 한 행에 놓은
정렬 행렬을 작성하세요. 연결이 끊기거나 중복되거나 서로 모순되는 지점을 표시하고,
그 문제가 타당도·재현성·윤리에 미치는 영향을 설명하세요.

혼합방법 연구라면 각 방법의 역할, 순서, 우선순위, 통합 시점과 불일치 결과를 다루는
규칙을 점검하세요. 데이터 생성부터 보관·공유·폐기까지 책임과 기록이 있는지도
검토하세요. 누락된 내용을 추정하여 채우지 말고 "정보 없음"으로 표시하세요.
마지막에는 필수 수정, 권장 수정, 선택 개선으로 우선순위를 나누세요.
```

### 제한 조건

- 문서에 없는 절차를 실제 계획처럼 보완하지 않는다.
- 방법을 추가할 때 자원·윤리·분석 부담을 함께 고려한다.
- 질적·양적 결과의 불일치를 임의로 해소하지 않는다.

### 검증 체크리스트

- [ ] 모든 연구 질문에 대응하는 자료와 분석이 있는가
- [ ] 측정과 분석이 개념 정의에 부합하는가
- [ ] 혼합방법의 통합 지점 또는 단일방법 선택 근거가 명확한가
- [ ] 수정 우선순위가 연구 타당도와 윤리 위험에 따라 정해졌는가
