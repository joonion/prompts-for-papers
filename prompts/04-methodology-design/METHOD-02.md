# METHOD-02. 표본과 자료수집 계획 설계

| 항목 | 내용 |
|---|---|
| 작업 | 모집단·표본·자료수집 절차와 편향 위험 구체화 |
| 태그 | `표본설계`, `자료수집`, `선택 편향` |
| 입력 유형 | 모집단, 표집틀, 연구 설계, 측정 항목, 자원과 윤리 제약 |
| 출력 형식 | 표본·수집 계획표와 편향 완화안 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

연구 대상과 분석 목적에 맞는 표집 전략과 재현 가능한 자료수집 절차를 설계한다.

### 필요한 입력

- `[목표 모집단과 분석 단위]`
- `[포함·제외 기준]`
- `[사용 가능한 표집틀과 모집 경로]`
- `[측정 변수 또는 질적 자료 유형]`
- `[예상되는 응답 거부·탈락·결측]`
- `[기간, 자원과 윤리 제약]`

### 프롬프트

```text
다음 연구를 위한 표본 및 자료수집 계획의 초안을 작성하세요.

[목표 모집단과 분석 단위]
[포함·제외 기준]
[사용 가능한 표집틀과 모집 경로]
[측정 변수 또는 질적 자료 유형]
[예상되는 응답 거부·탈락·결측]
[기간, 자원과 윤리 제약]

목표 모집단, 접근 가능한 모집단, 표집 단위와 분석 단위를 구분하세요. 가능한 표집
전략을 비교한 뒤 추천 전략, 모집 절차, 포함·제외 적용 방법, 중복 방지, 탈락·결측
대응과 품질 관리 절차를 단계별로 작성하세요. 대표성, 선택 편향, 비응답 편향,
측정 편향과 연구자 영향의 위험 및 완화 방법을 표로 제시하세요.

표본 크기는 필요한 효과 크기, 변동성, 검정력 또는 질적 포화 기준이 제공된 경우에만
계산하거나 판단하세요. 정보가 없으면 숫자를 만들지 말고 필요한 입력과 적절한 산정
절차를 제시하세요. 편의표집 결과를 전체 모집단으로 일반화하지 마세요.
```

### 제한 조건

- 근거 없이 표본 크기를 제안하지 않는다.
- 접근 가능한 모집단과 목표 모집단을 혼동하지 않는다.
- 취약집단의 모집과 동의 문제를 실행 편의보다 우선 검토한다.

### 검증 체크리스트

- [ ] 모집단, 표집 단위와 분석 단위가 구분되었는가
- [ ] 표본 크기 근거 또는 추가로 필요한 정보가 명시되었는가
- [ ] 편향별 완화책과 기록 절차가 있는가
- [ ] 모집·동의 절차가 연구윤리 승인 내용과 일치하는가
