# TOPIC-02. 연구 질문 후보 설계

| 항목 | 내용 |
|---|---|
| 작업 | 주제와 목적에 맞는 명확하고 답할 수 있는 연구 질문 작성 |
| 태그 | `연구 질문`, `PICO`, `개념화` |
| 입력 유형 | 주제, 연구 목적, 대상·맥락, 문헌 근거, 가능한 방법 |
| 출력 형식 | 질문 후보와 구성요소 분석표 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

탐색적·기술적·비교적·설명적 목적에 맞는 연구 질문을 만들고 각 질문의 요구 자료를 확인한다.

### 필요한 입력

- `[연구 주제와 목적]`
- `[연구 대상과 맥락]`
- `[현재까지 확인한 문헌의 핵심 내용]`
- `[접근 가능한 자료와 가능한 연구 방법]`
- `[적용하려는 질문 프레임워크—선택 사항]`

### 프롬프트

```text
다음 연구 맥락에서 답할 수 있고 범위가 명확한 연구 질문 후보를 설계하세요.

[연구 주제와 목적]
[연구 대상과 맥락]
[현재까지 확인한 문헌의 핵심 내용]
[접근 가능한 자료와 가능한 연구 방법]
[적용하려는 질문 프레임워크—선택 사항]

먼저 연구 목적을 탐색, 기술, 비교, 관계, 설명 중 어디에 가까운지 판단하고 근거를
제시하세요. 그 목적에 맞는 주 연구 질문 3개를 작성하세요. 각 질문에 대해 핵심 개념,
대상, 맥락, 시간 범위, 필요한 자료, 가능한 분석, 답할 수 없는 범위를 표로 정리하세요.
프레임워크가 제공되었다면 구성요소 대응표도 만드세요.

제공된 문헌만으로 확인되지 않은 연구 공백이나 인과관계를 단정하지 마세요. 개념의
정의가 모호하거나 자료가 부족하면 "확인 필요"라고 표시하고 연구자에게 물을 질문을
제시하세요. 마지막에는 가장 명료하고 실행 가능한 질문 1개를 추천하세요.
```

### 제한 조건

- 질문이 연구 방법이나 기대 결과를 미리 확정하지 않게 한다.
- 관찰 자료로 답할 질문에 인과 표현을 무리하게 사용하지 않는다.
- PICO 등 특정 프레임워크가 부적절하면 억지로 적용하지 않는다.

### 검증 체크리스트

- [ ] 질문마다 목적, 대상, 맥락과 분석 가능성이 연결되는가
- [ ] 예·아니요만으로 끝나거나 지나치게 넓은 질문이 제거되었는가
- [ ] 질문이 제공된 자료로 실제 답할 수 있는가
- [ ] 인과적 표현이 연구 설계에 의해 정당화되는가
