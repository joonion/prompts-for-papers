# TOPIC-01. 연구 주제 좁히기와 실행 가능성 비교

| 항목 | 내용 |
|---|---|
| 작업 | 넓은 관심사를 실행 가능한 연구 주제로 구체화 |
| 태그 | `주제 선정`, `범위 설정`, `실행 가능성` |
| 입력 유형 | 관심 분야, 대상, 맥락, 가용 자료, 기간과 자원 |
| 출력 형식 | 후보 주제 비교표와 추천 근거 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

넓은 관심사를 연구 대상, 현상, 맥락과 제약이 드러나는 비교 가능한 주제로 좁힌다.

### 필요한 입력

- `[관심 분야와 문제 상황]`
- `[연구하고 싶은 대상·현상·맥락]`
- `[가용한 데이터 또는 접근 가능한 현장]`
- `[기간, 인력, 예산과 연구자의 방법 역량]`
- `[피하고 싶은 범위 또는 접근]`

### 프롬프트

```text
아래 정보를 바탕으로 서로 다른 범위의 연구 주제 후보 5개를 제안하세요.

[관심 분야와 문제 상황]
[연구하고 싶은 대상·현상·맥락]
[가용한 데이터 또는 접근 가능한 현장]
[기간, 인력, 예산과 연구자의 방법 역량]
[피하고 싶은 범위 또는 접근]

각 후보를 한 문장으로 표현하고, 대상, 핵심 현상, 맥락, 가능한 자료, 필요한 방법,
예상 기여, 실행상 위험을 표로 비교하세요. 실행 가능성, 학술적 중요성, 범위의 명확성을
각각 1~5점으로 평가하되 점수의 근거를 설명하세요.

최신 연구 동향이나 실제 연구 공백을 제공 자료 없이 단정하지 마세요. 문헌 검토가
필요한 주장은 "문헌 확인 필요"로 표시하세요. 마지막에는 가장 균형 잡힌 후보 1개와
더 야심찬 후보 1개를 추천하고, 두 후보를 검증하기 위해 먼저 확인할 자료를 제시하세요.
```

### 제한 조건

- 새롭다는 이유만으로 실제 연구 공백이라고 단정하지 않는다.
- 가용 자원과 접근 권한을 무시한 주제를 우선하지 않는다.
- 점수는 객관적 사실이 아니라 비교를 위한 예비 판단임을 밝힌다.

### 검증 체크리스트

- [ ] 각 주제에 대상, 현상과 맥락이 드러나는가
- [ ] 실행 가능성 판단이 제공된 제약과 연결되는가
- [ ] 독창성 주장이 문헌 검토 전의 가설로 표시되었는가
- [ ] 후보들이 표현만 다르고 실질적으로 같은 주제는 아닌가
