# TOPIC-03. 연구 질문과 가설 품질 점검

| 항목 | 내용 |
|---|---|
| 작업 | 연구 질문을 평가하고 필요한 경우 검증 가능한 가설로 연결 |
| 태그 | `연구 질문 평가`, `가설`, `변수` |
| 입력 유형 | 연구 질문, 이론·선행연구 근거, 변수 정의, 연구 설계 |
| 출력 형식 | 평가표, 수정 질문, 가설·조작화 표 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

연구 질문의 명료성, 중요성, 실행 가능성과 설계 적합성을 점검하고 가설이 필요한 연구인지 판단한다.

### 필요한 입력

- `[연구 질문]`
- `[질문을 뒷받침하는 이론과 선행연구 근거]`
- `[핵심 개념 또는 변수의 정의]`
- `[예정된 연구 설계와 자료]`
- `[현실적 제약]`

### 프롬프트

```text
아래 연구 질문을 비판적으로 평가하세요.

[연구 질문]
[질문을 뒷받침하는 이론과 선행연구 근거]
[핵심 개념 또는 변수의 정의]
[예정된 연구 설계와 자료]
[현실적 제약]

명료성, 초점, 학술적 중요성, 답변 가능성, 개념의 측정 가능성, 설계 적합성,
윤리성과 실행 가능성을 각각 평가하고 근거를 제시하세요. 문제를 심각도 순으로 정리한
뒤 수정된 연구 질문 2개를 제안하고 무엇이 달라졌는지 설명하세요.

이 연구가 가설 검증형인지 탐색형인지 판단하세요. 가설 검증형일 때만 이론적 근거와
방향성이 드러나는 가설을 제안하고, 독립·종속·통제 변수와 조작적 정의를 표로
정리하세요. 탐색형이라면 억지로 가설을 만들지 말고 탐색 질문과 분석 초점을 제시하세요.
제공되지 않은 이론적 근거나 예상 효과를 만들지 말고 "근거 확인 필요"로 표시하세요.
```

### 제한 조건

- 결과를 예상한 뒤 그에 맞춰 가설을 소급해 만들지 않는다.
- 가설과 통계적 귀무가설을 혼동하지 않는다.
- 자료와 설계가 뒷받침하지 않는 인과 가설을 제안하지 않는다.

### 검증 체크리스트

- [ ] 평가 기준마다 구체적인 근거가 있는가
- [ ] 수정 질문이 원래 연구 목적을 유지하는가
- [ ] 가설의 필요성이 연구 유형과 연결되는가
- [ ] 변수 정의와 측정 방식이 연구자가 확인할 수 있게 표시되었는가
