# EDIT-01. 주장–근거–추론 구조 점검

| 항목 | 내용 |
|---|---|
| 작업 | 논문의 핵심 주장과 근거 사이의 논리적 연결 검토 |
| 태그 | `논증`, `근거`, `반론`, `논리 점검` |
| 입력 유형 | 원고, 연구 질문, 근거표, 핵심 결론 |
| 출력 형식 | 논증 지도, 문제 진단, 수정 제안 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

핵심 주장, 이를 지지하는 근거와 그 사이의 추론을 분리해 약한 연결과 과도한 결론을 찾는다.

### 필요한 입력

- `[연구 질문과 중심 주장]`
- `[검토할 원고]`
- `[검증된 근거표 또는 결과]`
- `[논문의 적용 범위와 주요 한계]`

### 프롬프트

```text
다음 원고의 논증 구조를 제공된 근거 범위 안에서 분석하세요.

[연구 질문과 중심 주장]
[검토할 원고]
[검증된 근거표 또는 결과]
[논문의 적용 범위와 주요 한계]

주요 주장별로 주장, 직접 근거, 주장을 뒷받침하는 추론, 숨은 가정, 반대 근거,
결론의 적용 범위를 논증 지도에 정리하세요. 근거 없음, 상관–인과 혼동, 과도한 일반화,
선택적 근거, 순환 논증, 개념 변화와 반론 누락을 구체적인 문장 위치와 함께 표시하세요.

문제마다 근거 추가, 주장 약화, 범위 한정, 문장 이동 또는 삭제 중 적절한 수정 유형을
추천하세요. 제공되지 않은 근거를 새로 만들지 말고 "추가 근거 필요"로 표시하세요.
가장 강한 합리적 반론을 구성한 뒤 현재 근거로 답할 수 있는 부분과 답할 수 없는 부분을
구분하세요. 마지막에는 중심 주장을 유지한 최소 수정안을 제시하세요.
```

### 제한 조건

- 저자에게 불리한 근거를 임의로 생략하지 않는다.
- 반론에 답하기 위해 새로운 자료나 결과를 만들지 않는다.
- 문체의 자신감을 근거의 강도로 오해하지 않는다.

### 검증 체크리스트

- [ ] 핵심 주장마다 직접 근거와 추론이 구분되었는가
- [ ] 지적한 문제에 정확한 문장 위치가 있는가
- [ ] 반론이 허수아비가 아니라 실제로 강한 형태인가
- [ ] 수정 후 결론의 강도가 근거 수준과 일치하는가
