# EDIT-03. 본문 인용과 참고문헌 일치 감사

| 항목 | 내용 |
|---|---|
| 작업 | 인용의 존재·정확성·주장 지원 여부와 목록 일치 점검 |
| 태그 | `인용 검증`, `참고문헌`, `출처 감사` |
| 입력 유형 | 원고, 참고문헌 목록, 원문 또는 검증된 서지정보 |
| 출력 형식 | 인용 감사표, 불일치 목록, 확인 우선순위 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

본문 인용과 참고문헌 목록의 기계적 일치뿐 아니라 해당 문헌이 실제로 주장을 뒷받침하는지 확인한다.

### 필요한 입력

- `[본문 인용이 포함된 원고]`
- `[참고문헌 목록 또는 BibTeX 자료]`
- `[인용 문헌의 원문·발췌문·검증된 메타데이터]`
- `[사용할 인용 스타일]`

### 프롬프트

```text
제공된 자료만 사용하여 본문 인용과 참고문헌을 감사하세요.

[본문 인용이 포함된 원고]
[참고문헌 목록 또는 BibTeX 자료]
[인용 문헌의 원문·발췌문·검증된 메타데이터]
[사용할 인용 스타일]

본문의 모든 인용을 추출하여 위치, 인용이 붙은 주장, 대응 참고문헌, 원문 근거 위치,
지원 정도를 표로 정리하세요. 지원 정도는 직접 지원, 부분 지원, 맥락 불일치,
원문 확인 불가로 구분하고 이유를 적으세요. 본문에만 있는 인용, 목록에만 있는 문헌,
저자·연도 불일치와 동일 저자·연도 구분 오류를 별도로 찾으세요.

DOI, 제목, 저자, 학술지와 페이지는 제공된 검증 자료에서만 확인하세요. 없는 정보를
모델의 기억으로 채우거나 새 문헌을 추천하지 마세요. 인용 스타일 문제와 내용의 근거
문제를 구분하고, 수정 우선순위를 연구 결론에 미치는 영향에 따라 정하세요. 마지막에는
사람이 원문에서 다시 확인할 항목을 체크리스트로 작성하세요.
```

### 제한 조건

- 존재 여부를 확인하지 않은 DOI나 서지정보를 생성하지 않는다.
- 인용이 있다는 사실만으로 주장이 지지된다고 판단하지 않는다.
- 2차 인용을 원문을 직접 확인한 것처럼 처리하지 않는다.

### 검증 체크리스트

- [ ] 본문 인용과 참고문헌이 양방향으로 모두 대조되었는가
- [ ] 각 중요 주장에 대한 원문 지원 정도가 평가되었는가
- [ ] 직접 인용의 문구와 위치가 원문과 일치하는가
- [ ] 서지정보를 DOI 등록기관, 출판사 또는 데이터베이스에서 다시 확인했는가
