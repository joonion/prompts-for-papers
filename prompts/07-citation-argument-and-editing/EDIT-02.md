# EDIT-02. 구조·명료성·학술 문체 교정

| 항목 | 내용 |
|---|---|
| 작업 | 의미와 근거를 보존하면서 원고의 구조와 문장을 개선 |
| 태그 | `문장 교정`, `명료성`, `응집성`, `학술 문체` |
| 입력 유형 | 원고, 대상 독자, 문체 규정, 보존해야 할 용어와 인용 |
| 출력 형식 | 진단표, 수정본, 변경 기록 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

내용을 새로 만들지 않고 문단 흐름, 문장 명료성, 간결성, 용어와 문체의 일관성을 개선한다.

### 필요한 입력

- `[교정할 원고]`
- `[논문 섹션과 대상 독자]`
- `[적용할 문체·스타일 규정]`
- `[뜻을 바꾸면 안 되는 전문용어·수치·인용]`
- `[선호하는 교정 강도—최소·보통·적극]`

### 프롬프트

```text
아래 원고의 사실, 주장 강도, 수치와 인용을 바꾸지 않고 구조와 표현을 교정하세요.

[교정할 원고]
[논문 섹션과 대상 독자]
[적용할 문체·스타일 규정]
[뜻을 바꾸면 안 되는 전문용어·수치·인용]
[선호하는 교정 강도—최소·보통·적극]

먼저 문단별 기능과 논리 흐름을 진단하여 주제문 부재, 순서 문제, 반복, 불명확한 지시어,
과도한 명사화, 불필요한 수동태, 긴 문장과 용어 불일치를 표시하세요. 그다음 지정된
교정 강도에 맞춰 수정본을 작성하세요.

새로운 사실, 인용, 근거, 결과나 해석을 추가하지 마세요. 불명확하지만 연구자만 결정할
수 있는 내용은 임의로 고치지 말고 "[저자 확인]"으로 표시하세요. 수정 후에는 의미에
영향을 줄 수 있는 변경, 문단 이동, 용어 통일과 삭제한 중복을 변경 기록표로 제시하세요.
마지막에는 수정 과정에서 의도치 않게 주장 강도가 높아진 문장이 없는지 점검하세요.
```

### 제한 조건

- 문법 교정을 이유로 연구 내용이나 결과를 바꾸지 않는다.
- 모든 문장을 수동태나 어려운 학술어로 바꾸지 않는다.
- 직접 인용문과 인용 키는 연구자의 허락 없이 수정하지 않는다.

### 검증 체크리스트

- [ ] 원문과 수정본의 사실·수치·인용이 일치하는가
- [ ] 전문용어가 문서 전체에서 일관되는가
- [ ] 각 문단에 분명한 기능과 논리적 연결이 있는가
- [ ] 의미 변화 가능성이 있는 수정이 변경 기록에 포함되었는가
