# WRITE-02. 제공된 근거로 논문 섹션 초안 작성

| 항목 | 내용 |
|---|---|
| 작업 | 검증된 메모와 근거를 이용해 특정 섹션 초안 작성 |
| 태그 | `초안`, `근거 기반 글쓰기`, `문단 설계` |
| 입력 유형 | 섹션 목적, 개요, 근거 묶음, 인용 키, 문체 규정 |
| 출력 형식 | 근거 연결표, 섹션 초안, 미해결 표시 목록 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

AI가 내용을 발명하지 않도록 검증된 근거와 작성 메모의 범위 안에서 논문 섹션 초안을 만든다.

### 필요한 입력

- `[작성할 섹션과 그 목적]`
- `[절·문단별 개요]`
- `[검증된 연구 메모, 결과 또는 문헌 근거]`
- `[사용 가능한 인용 키와 근거 위치]`
- `[대상 독자, 문체, 분량과 투고처 규정]`

### 프롬프트

```text
아래에 제공한 자료만 사용하여 [작성할 섹션]의 초안을 작성하세요.

[작성할 섹션과 그 목적]
[절·문단별 개요]
[검증된 연구 메모, 결과 또는 문헌 근거]
[사용 가능한 인용 키와 근거 위치]
[대상 독자, 문체, 분량과 투고처 규정]

초안을 쓰기 전에 개요의 각 주장과 사용할 근거를 연결한 표를 작성하세요. 근거가 없는
주장은 삭제하거나 "[근거 필요]"로 표시하세요. 각 문단은 핵심 문장, 근거, 해석과
다음 문단으로의 연결이 드러나게 구성하세요. 인용은 제공된 인용 키만 사용하고,
페이지나 서지정보가 없으면 만들지 말고 "[위치 확인 필요]"로 표시하세요.

연구자가 수행하지 않은 방법, 분석과 결과를 추가하지 마세요. 문헌의 주장과 이 연구의
결과를 구분하고, 불확실성과 한계를 유지하세요. 초안 뒤에는 새로 생성한 해석적 문장,
원자료 확인이 필요한 문장, 연구자가 결정해야 할 문장을 별도 목록으로 제시하세요.
```

### 제한 조건

- 제공되지 않은 문헌, 인용 키, 수치 또는 절차를 만들지 않는다.
- 원문의 표현을 길게 복제하거나 표절 회피를 목적으로 바꾸어 쓰지 않는다.
- `[근거 필요]`와 `[위치 확인 필요]` 표시를 자연스러운 문장으로 감추지 않는다.

### 검증 체크리스트

- [ ] 모든 사실 주장과 수치가 제공 자료에 연결되는가
- [ ] 인용 키와 근거 위치가 원문·참고문헌 관리 도구와 일치하는가
- [ ] 결과와 해석, 저자의 주장과 연구자의 주장이 구분되는가
- [ ] 최종 문장은 연구자가 직접 읽고 책임질 수 있는가
