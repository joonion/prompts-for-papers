# WRITE-01. 연구 질문 중심의 논문 개요 설계

| 항목 | 내용 |
|---|---|
| 작업 | 연구 질문과 근거 흐름에 맞는 논문 구조 설계 |
| 태그 | `논문 개요`, `IMRaD`, `논증 구조` |
| 입력 유형 | 연구 질문, 핵심 주장, 방법과 결과 요약, 투고처 구조 |
| 출력 형식 | 절별 기능표, 논증 흐름, 집필 순서 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

관습적인 목차만 나열하지 않고 각 절과 단락이 연구 질문에 어떤 역할을 하는지 설계한다.

### 필요한 입력

- `[연구 질문과 연구 목적]`
- `[검증된 문헌 종합과 연구 공백]`
- `[연구 방법 요약]`
- `[검증된 핵심 결과]`
- `[주요 기여와 한계]`
- `[논문 유형과 투고처의 구조·분량 규정]`

### 프롬프트

```text
아래 정보를 바탕으로 연구 질문에 답하는 논문 개요를 설계하세요.

[연구 질문과 연구 목적]
[검증된 문헌 종합과 연구 공백]
[연구 방법 요약]
[검증된 핵심 결과]
[주요 기여와 한계]
[논문 유형과 투고처의 구조·분량 규정]

먼저 논문의 중심 주장과 독자가 따라가야 할 논리 흐름을 한 문단으로 요약하세요.
그다음 각 절과 하위 절에 대해 기능, 답할 질문, 사용할 근거, 핵심 문장, 앞뒤 절과의
연결, 예상 분량을 표로 작성하세요. 결과 절에는 관찰된 사실만, 논의 절에는 해석과
선행연구 비교가 배치되도록 구분하세요.

제공되지 않은 결과, 문헌 또는 방법을 빈칸을 채우기 위해 만들지 마세요. 정보가 없는
부분은 "자료 필요"로 표시하세요. 중복되는 절과 연구 질문에 기여하지 않는 내용을
찾아 정리하고, 마지막에는 실제 집필에 효율적인 절 순서를 제안하세요.
```

### 제한 조건

- 모든 논문에 IMRaD 구조를 기계적으로 강제하지 않는다.
- 결과와 논의를 섞거나 새로운 결과를 추가하지 않는다.
- 투고처 규정이 없으면 특정 형식을 공식 요구사항처럼 단정하지 않는다.

### 검증 체크리스트

- [ ] 모든 절이 연구 질문 또는 중심 주장에 기여하는가
- [ ] 각 주장에 사용할 근거가 지정되었는가
- [ ] 결과, 해석과 한계의 위치가 구분되었는가
- [ ] 투고처의 최신 구조와 분량 규정을 다시 확인했는가
