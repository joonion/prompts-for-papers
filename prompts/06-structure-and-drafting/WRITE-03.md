# WRITE-03. 완성 원고에서 제목·초록·키워드 도출

| 항목 | 내용 |
|---|---|
| 작업 | 완성된 원고의 실제 내용에 맞는 제목·초록·키워드 작성 |
| 태그 | `제목`, `초록`, `키워드` |
| 입력 유형 | 완성 원고 또는 검증된 구조화 요약, 투고처 규정 |
| 출력 형식 | 사실 추출표, 제목 후보, 구조화 초록, 키워드 후보 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

연구가 실제로 수행한 내용과 결과를 정확히 반영하는 제목, 초록과 검색 키워드를 작성한다.

### 필요한 입력

- `[완성 원고 또는 목적·방법·결과·결론의 검증된 요약]`
- `[논문 유형]`
- `[투고처의 제목·초록·키워드 규정]`
- `[반드시 포함하거나 피할 용어]`

### 프롬프트

```text
아래 원고에 실제로 명시된 내용만 사용하여 제목, 초록과 키워드 후보를 작성하세요.

[완성 원고 또는 목적·방법·결과·결론의 검증된 요약]
[논문 유형]
[투고처의 제목·초록·키워드 규정]
[반드시 포함하거나 피할 용어]

먼저 연구 목적, 설계, 대상·자료, 주요 분석, 핵심 결과, 결론과 중요한 한계를 원고에서
추출한 사실표를 만드세요. 확인할 수 없는 요소는 "원고에서 확인 불가"로 표시하세요.
그 사실표를 바탕으로 강조점이 다른 제목 5개와 각각의 장단점을 제시하세요.

투고처 규정에 맞는 초록을 작성하고 목적·방법·결과·결론의 균형을 점검하세요.
결과에는 원고에 있는 수치만 사용하고, 인과관계와 일반화 범위를 확대하지 마세요.
키워드는 제목의 단순 반복을 줄이고 연구 대상, 개념, 방법과 맥락을 반영한 후보를
제안하세요. 통제어 여부는 공식 색인에서 확인하지 않았다면 "확인 필요"로 표시하세요.
```

### 제한 조건

- 원고에 없는 결과, 표본 특성이나 기여를 추가하지 않는다.
- 관찰 연구 제목과 초록에 근거 없는 인과 표현을 쓰지 않는다.
- 투고처의 최신 규정과 통제어를 실제 확인 없이 확정하지 않는다.

### 검증 체크리스트

- [ ] 제목과 초록의 모든 정보가 원고에서 확인되는가
- [ ] 초록의 수치가 결과표와 정확히 일치하는가
- [ ] 연구 설계와 결론의 강도가 일치하는가
- [ ] 글자 수, 구조와 키워드 수가 최신 투고 규정을 따르는가
