# PREP-02. 연구자료 민감정보 점검과 입력 최소화

| 항목 | 내용 |
|---|---|
| 작업 | AI 도구에 자료를 입력하기 전 위험 분류와 비식별화 계획 수립 |
| 태그 | `개인정보`, `데이터 보안`, `비식별화` |
| 입력 유형 | 실제 데이터가 아닌 자료 유형 설명, 동의 범위, 도구의 데이터 처리 정책 |
| 출력 형식 | 위험 목록, 최소 입력안, 대체 작업안 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

개인정보나 미공개 연구자료를 AI 도구에 입력하기 전에 위험을 식별하고 더 안전한 입력 방식을 설계한다.

### 필요한 입력

- `[자료 유형과 포함 필드에 대한 설명—실제 값은 제외]`
- `[연구참여자 동의와 데이터 이용 범위]`
- `[기관의 데이터 보안 규정]`
- `[AI 도구의 저장·학습·보존 정책]`
- `[수행하려는 작업]`

### 프롬프트

```text
실제 원자료를 요구하지 말고, 아래의 자료 유형 설명만으로 AI 입력 위험을 점검하세요.

[자료 유형과 포함 필드에 대한 설명—실제 값은 제외]
[연구참여자 동의와 데이터 이용 범위]
[기관의 데이터 보안 규정]
[AI 도구의 저장·학습·보존 정책]
[수행하려는 작업]

다음을 표로 작성하세요.
- 위험 요소
- 영향을 받는 정보 또는 사람
- 위험 수준과 판단 근거
- 입력 전에 제거·가명처리·집계할 항목
- 최소한으로 필요한 대체 입력
- 로컬 처리나 합성자료 등 더 안전한 대안
- 담당자에게 확인할 사항

정책이나 동의 범위가 제공되지 않은 경우 허용 여부를 추정하지 말고 "확인 필요"로
표시하세요. 비식별화만으로 재식별 위험이 사라진다고 단정하지 마세요. 마지막에는
현재 정보만으로 입력 가능, 조건부 가능, 입력 중단 중 하나를 예비 판단으로 제시하고
그 판단이 기관의 공식 승인을 대신하지 않는다고 명시하세요.
```

### 제한 조건

- 이름, 연락처, 식별번호 등 실제 민감정보를 추가로 요구하지 않는다.
- 비식별화의 효과를 과장하지 않는다.
- 도구의 데이터 처리 정책을 제공 자료 없이 추정하지 않는다.

### 검증 체크리스트

- [ ] 직접 식별자와 간접 식별자가 모두 검토되었는가
- [ ] 동의 범위와 도구 정책의 미확인 사항이 표시되었는가
- [ ] 원자료를 보내지 않는 대안이 제시되었는가
- [ ] 최종 승인 주체가 명확한가
