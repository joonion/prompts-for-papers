# PREP-03. 연구윤리 사전 검토

| 항목 | 내용 |
|---|---|
| 작업 | 연구계획의 윤리적 쟁점과 보완 사항 탐색 |
| 태그 | `연구윤리`, `IRB`, `이해상충`, `취약집단` |
| 입력 유형 | 연구계획 요약, 참여자·자료·절차, 예상 이익과 위험 |
| 출력 형식 | 쟁점별 검토표와 보완 질문 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

공식 심의나 지도교수 검토 전에 연구계획에서 놓치기 쉬운 윤리적 쟁점을 체계적으로 찾는다.

### 필요한 입력

- `[연구 목적과 설계]`
- `[연구참여자 또는 데이터 출처]`
- `[모집·동의·보상 절차]`
- `[예상되는 위험과 이익]`
- `[자료 보관·공유·폐기 계획]`
- `[연구자 역할과 이해상충 가능성]`

### 프롬프트

```text
다음 연구계획을 공식 심의 전 사전 점검 관점에서 검토하세요.

[연구 목적과 설계]
[연구참여자 또는 데이터 출처]
[모집·동의·보상 절차]
[예상되는 위험과 이익]
[자료 보관·공유·폐기 계획]
[연구자 역할과 이해상충 가능성]

검토표에 다음 열을 포함하세요: 쟁점, 계획서의 관련 내용, 잠재 위험,
영향을 받는 대상, 보완 방안, 연구자가 답해야 할 질문. 자율성, 위해 최소화,
공정성, 개인정보, 취약집단, 기만, 보상, 데이터 2차 이용, 이해상충과 결과 공개를
점검하세요.

제공되지 않은 사실을 가정하지 말고 "정보 없음"으로 표시하세요. 법적 적합성이나
심의 면제를 확정하지 말고, 공식 연구윤리위원회와 소속기관의 판단이 필요한 항목을
분리하세요. 마지막에는 우선 보완할 3개 항목과 그 선정 이유를 제시하세요.
```

### 제한 조건

- 공식 IRB 심사, 법률 자문 또는 기관 승인을 대신하지 않는다.
- 참여자나 자료에 관한 누락 정보를 만들어 채우지 않는다.
- 위험을 나열하는 데 그치지 않고 완화 방안과 확인 질문을 연결한다.

### 검증 체크리스트

- [ ] 주요 윤리 원칙과 데이터 생애주기가 모두 검토되었는가
- [ ] 제공된 정보와 누락된 정보가 구분되었는가
- [ ] 공식 판단이 필요한 항목을 별도로 표시했는가
- [ ] 보완안이 연구 설계와 모순되지 않는지 연구자가 확인했는가
