# COMM-02. 일반 독자를 위한 연구 요약 작성

| 항목 | 내용 |
|---|---|
| 작업 | 전문 연구를 정확성을 유지하며 쉬운 언어로 설명 |
| 태그 | `대중 소통`, `쉬운 설명`, `연구 요약` |
| 입력 유형 | 검증된 논문 요약, 대상 독자, 분량과 채널 |
| 출력 형식 | 핵심 사실표, 대중 요약, 용어 설명 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

비전문 독자가 연구의 필요성, 수행 방법, 발견, 한계와 의미를 오해 없이 이해하도록 설명한다.

### 필요한 입력

- `[검증된 연구 요약 또는 원고]`
- `[대상 독자와 예상 배경지식]`
- `[게시 채널과 목표 분량]`
- `[반드시 유지할 수치·용어·주의사항]`

### 프롬프트

```text
아래 연구를 지정한 일반 독자가 이해할 수 있는 언어로 요약하세요.

[검증된 연구 요약 또는 원고]
[대상 독자와 예상 배경지식]
[게시 채널과 목표 분량]
[반드시 유지할 수치·용어·주의사항]

먼저 연구가 다룬 문제, 연구 질문, 방법, 핵심 결과, 불확실성, 한계와 적용 범위를
사실표로 추출하세요. 그 사실만 사용하여 왜 중요한가, 무엇을 했는가, 무엇을 알았는가,
무엇을 아직 모르는가 순서로 요약하세요. 전문용어는 쉬운 말로 풀고 필요한 경우 짧은
비유를 사용하되 비유가 설명하지 못하는 범위도 밝히세요.

인과관계, 위험, 확률과 효과 크기를 과장하지 마세요. 통계적 유의성을 일상적으로 큰
효과라는 뜻으로 바꾸지 마세요. 제공되지 않은 사례나 수치를 만들지 말고, 개인에게
직접 적용할 수 없는 결과는 그렇게 명시하세요. 마지막에는 제목 후보 3개와 오해를
부를 수 있어 피한 표현을 제시하세요.
```

### 제한 조건

- 쉬운 설명을 위해 과학적 불확실성과 한계를 삭제하지 않는다.
- 건강·정책·행동에 관한 개인 조언으로 확대하지 않는다.
- 선정적인 제목이나 절대적 표현을 사용하지 않는다.

### 검증 체크리스트

- [ ] 요약의 모든 사실과 수치가 원고에서 확인되는가
- [ ] 인과와 상관, 절대위험과 상대위험이 구분되는가
- [ ] 대상 독자가 이해하기 어려운 용어가 설명되었는가
- [ ] 한계와 적용 범위가 눈에 띄게 포함되었는가
