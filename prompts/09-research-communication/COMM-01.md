# COMM-01. 학회 발표 스토리라인과 슬라이드 개요 설계

| 항목 | 내용 |
|---|---|
| 작업 | 제한 시간 안에 핵심 연구를 전달하는 발표 구조 설계 |
| 태그 | `학회 발표`, `슬라이드`, `질의응답` |
| 입력 유형 | 논문 요약, 청중, 발표 시간, 형식과 공개 제한 |
| 출력 형식 | 스토리라인, 슬라이드별 개요, 시간표, 예상 질문 |
| 위험도 | 중간 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

논문의 모든 내용을 압축하는 대신 청중과 발표 시간에 맞는 하나의 명확한 연구 이야기를 설계한다.

### 필요한 입력

- `[검증된 연구 목적·방법·결과·결론·한계]`
- `[학회와 청중의 배경지식]`
- `[발표 시간과 질의응답 시간]`
- `[슬라이드 수·화면 비율·접근성 규정]`
- `[공개하면 안 되는 정보]`

### 프롬프트

```text
아래 연구 내용을 이용하여 학회 발표의 스토리라인과 슬라이드 개요를 설계하세요.

[검증된 연구 목적·방법·결과·결론·한계]
[학회와 청중의 배경지식]
[발표 시간과 질의응답 시간]
[슬라이드 수·화면 비율·접근성 규정]
[공개하면 안 되는 정보]

청중이 발표 후 기억해야 할 핵심 메시지를 한 문장으로 정하고, 문제–질문–접근–근거–
의미–한계 흐름을 설계하세요. 슬라이드별로 제목, 한 가지 핵심 메시지, 사용할 근거,
적합한 시각자료, 발표자 메모와 예상 시간을 표로 작성하세요. 표·그림은 검증된 결과만
사용하고 한 슬라이드에 여러 주장을 과도하게 넣지 마세요.

제공되지 않은 수치, 사례나 성과를 만들지 마세요. 한계를 숨기지 말고 결론의 범위를
설계와 일치시키세요. 색상 이외의 구분, 읽을 수 있는 글자 크기, 대체 설명 등 접근성
점검을 포함하세요. 마지막에는 까다로운 예상 질문 8개와 원고에 근거한 답변 요점을
제시하고 답할 수 없는 질문에는 "추가 확인 필요"라고 표시하세요.
```

### 제한 조건

- 시선을 끌기 위해 연구 결과나 일반화 범위를 과장하지 않는다.
- 공개 제한이 있는 데이터와 참여자 정보를 시각자료에 포함하지 않는다.
- 슬라이드에 없는 근거를 발표자가 말로 보완하도록 가정하지 않는다.

### 검증 체크리스트

- [ ] 발표 시간이 슬라이드별 합계와 일치하는가
- [ ] 모든 수치와 그림이 논문의 검증된 결과와 일치하는가
- [ ] 청중 수준에 맞지 않는 전문용어가 설명되었는가
- [ ] 접근성 및 공개 제한 조건을 충족하는가
