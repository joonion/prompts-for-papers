# COMM-03. 근거 수준을 반영한 정책 브리프 작성

| 항목 | 내용 |
|---|---|
| 작업 | 연구 결과와 정책 선택지를 근거 수준에 맞게 연결 |
| 태그 | `정책 브리프`, `의사결정`, `근거 수준` |
| 입력 유형 | 검증된 연구 결과, 정책 맥락, 이해관계자, 실행 제약 |
| 출력 형식 | 요약, 근거표, 정책 선택지와 실행 고려사항 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

단일 연구의 결과를 정책 권고로 과도하게 확대하지 않으면서 의사결정자가 검토할 선택지를 제시한다.

### 필요한 입력

- `[검증된 연구 결과와 근거 수준]`
- `[정책 문제와 현재 맥락]`
- `[대상 의사결정자와 이해관계자]`
- `[비용, 형평성, 실행 가능성과 법적 제약 정보]`
- `[브리프 분량과 형식]`

### 프롬프트

```text
아래 자료만 사용하여 정책 브리프 초안을 작성하세요.

[검증된 연구 결과와 근거 수준]
[정책 문제와 현재 맥락]
[대상 의사결정자와 이해관계자]
[비용, 형평성, 실행 가능성과 법적 제약 정보]
[브리프 분량과 형식]

먼저 연구가 직접 보여준 사실, 저자의 해석, 정책에 적용하기 위해 필요한 추가 가정을
구분한 표를 작성하세요. 그다음 핵심 메시지, 문제의 범위, 근거, 불확실성, 영향을 받는
집단, 정책 선택지, 선택지별 기대 이익·위험·형평성·실행 조건, 모니터링 지표 순서로
브리프를 구성하세요.

단일 연구나 관찰 연구를 확정적 정책 효과의 증거로 제시하지 마세요. 제공되지 않은
비용, 법률, 인구 규모나 효과 추정치를 만들지 말고 "추가 근거 필요"로 표시하세요.
하나의 권고만 단정하기보다 근거 수준에 맞는 복수의 선택지를 제시하세요. 마지막에는
결정 전에 필요한 추가 자료와 이해관계자 협의 질문을 작성하세요.
```

### 제한 조건

- 과학적 결과와 가치 판단 또는 정책 선호를 혼합하지 않는다.
- 비용과 형평성 자료가 없는데도 최적 정책을 확정하지 않는다.
- 적용 대상과 맥락을 원 연구보다 넓게 일반화하지 않는다.

### 검증 체크리스트

- [ ] 직접 근거, 해석과 정책 가정이 구분되었는가
- [ ] 선택지별 이익·위험·형평성과 실행 조건이 비교되었는가
- [ ] 모든 수치와 법적 주장을 신뢰할 수 있는 자료에서 다시 확인했는가
- [ ] 근거 수준에 비해 권고의 강도가 지나치지 않은가
