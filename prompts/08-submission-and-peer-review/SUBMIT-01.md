# SUBMIT-01. 후보 학술지 적합성 비교

| 항목 | 내용 |
|---|---|
| 작업 | 연구와 후보 학술지의 범위·독자·요건 비교 |
| 태그 | `학술지 선택`, `투고 규정`, `적합성` |
| 입력 유형 | 논문 요약, 후보 학술지의 공식 안내, 현실적 제약 |
| 출력 형식 | 적합성 비교표, 제외 사유, 확인 질문 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

모델의 기억이나 임의의 지표가 아니라 후보 학술지의 최신 공식 자료를 기준으로 투고 적합성을 비교한다.

### 필요한 입력

- `[논문의 제목·초록·방법·기여·대상 독자]`
- `[후보 학술지 목록]`
- `[각 학술지의 공식 Aims & Scope와 저자 지침]`
- `[출판비, 공개 방식, 일정 등 연구자의 제약]`
- `[중요하게 평가할 기준]`

### 프롬프트

```text
아래에 제공된 학술지 공식 안내만 사용하여 논문과 후보 학술지의 적합성을 비교하세요.

[논문의 제목·초록·방법·기여·대상 독자]
[후보 학술지 목록]
[각 학술지의 공식 Aims & Scope와 저자 지침]
[출판비, 공개 방식, 일정 등 연구자의 제약]
[중요하게 평가할 기준]

학술지별로 주제 범위, 독자, 논문 유형, 방법론 수용성, 분량·형식, 데이터·윤리 정책,
공개 방식과 비용, 논문과의 적합 근거를 비교하세요. 각 판단에는 제공 자료의 문구나
위치를 연결하세요. 적합, 조건부 적합, 부적합으로 분류하고 결정적 이유를 설명하세요.

제공되지 않은 영향력 지표, 게재율, 심사 기간, 비용이나 평판을 모델의 기억으로
채우지 말고 "최신 공식 정보 확인 필요"로 표시하세요. 약탈적 학술지 여부를 근거 없이
단정하지 말고 확인해야 할 공식 등록·정책 항목을 제시하세요. 마지막에는 우선 검토할
후보 2개와 투고 전 확인 질문을 제안하세요.
```

### 제한 조건

- 최신성이 중요한 정보는 공식 웹페이지 제공 없이 확정하지 않는다.
- 영향력 지표만으로 학술지 적합성을 평가하지 않는다.
- 투고를 보장하거나 게재 가능성을 수치로 만들지 않는다.

### 검증 체크리스트

- [ ] 모든 적합성 판단에 공식 안내 근거가 있는가
- [ ] 비용, 공개 방식과 심사 정책의 기준일을 확인했는가
- [ ] 연구 주제뿐 아니라 방법·논문 유형·독자가 비교되었는가
- [ ] 최종 후보의 최신 지침을 학술지 웹사이트에서 다시 확인했는가
