# SUBMIT-02. 투고 전 모의 동료심사

| 항목 | 내용 |
|---|---|
| 작업 | 원고의 기여·방법·분석·서술을 심사 기준으로 검토 |
| 태그 | `동료심사`, `원고 검토`, `투고 전 점검` |
| 입력 유형 | 전체 원고, 투고처 범위와 심사 기준, 보조자료 |
| 출력 형식 | 요약, 주요·경미 의견, 판정 근거, 수정 우선순위 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

투고 전에 실제 심사자가 제기할 가능성이 높은 문제를 근거 위치와 함께 찾는다.

### 필요한 입력

- `[전체 원고]`
- `[투고처의 범위와 심사 기준]`
- `[보고 지침 또는 체크리스트]`
- `[부록·데이터·코드 설명—해당하는 경우]`

### 프롬프트

```text
다음 원고를 투고처의 심사 기준과 제공된 보고 지침에 따라 모의 심사하세요.

[전체 원고]
[투고처의 범위와 심사 기준]
[보고 지침 또는 체크리스트]
[부록·데이터·코드 설명—해당하는 경우]

먼저 연구 질문, 설계, 핵심 결과, 기여와 저자가 밝힌 한계를 중립적으로 요약하세요.
그다음 독창성 주장의 근거, 문헌 검토, 방법의 적합성, 표본과 측정, 분석, 결과 보고,
해석의 범위, 재현성, 윤리, 표·그림과 문장 명료성을 평가하세요.

각 의견을 주요 또는 경미로 분류하고, 원고의 정확한 위치, 문제의 이유, 필요한 수정,
수정이 결론에 미칠 영향을 제시하세요. 원고에 없는 사실을 가정하거나 새로운 결과를
요구하지 마세요. 추가 연구가 필수인지 선택적 개선인지 구분하세요. 장점도 구체적인
근거와 함께 제시하고, 마지막에는 투고 전 필수 수정 순서를 작성하세요.
```

### 제한 조건

- 취향이나 권위에 기대어 비판하지 않는다.
- 현재 연구 질문에 필요하지 않은 대규모 추가 실험을 자동으로 요구하지 않는다.
- 원고에 없는 윤리 승인이나 데이터 공개 상태를 가정하지 않는다.

### 검증 체크리스트

- [ ] 모든 지적에 원고 위치와 심사 기준이 연결되는가
- [ ] 주요 의견과 경미 의견의 구분이 일관되는가
- [ ] 장점과 한계가 모두 구체적으로 평가되었는가
- [ ] 필수 수정과 선택적 개선이 구분되었는가
