# SUBMIT-03. 심사 의견 분류와 답변서 작성

| 항목 | 내용 |
|---|---|
| 작업 | 편집자·심사자 의견을 추적하고 근거 있는 답변서 작성 |
| 태그 | `심사 대응`, `답변서`, `수정 추적` |
| 입력 유형 | 심사 의견, 원고, 실제 수정 내용, 추가 분석 결과 |
| 출력 형식 | 대응표, 답변 초안, 미해결 항목 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

모든 심사 의견에 빠짐없이 답하고 실제 수정 내용과 원고 위치를 정확히 연결한다.

### 필요한 입력

- `[편집자와 심사자의 원문 의견]`
- `[수정 전 원고]`
- `[연구자가 실제로 수행한 수정과 추가 분석]`
- `[수정 후 원고의 위치 정보]`
- `[수용하기 어려운 의견과 그 근거]`

### 프롬프트

```text
아래 심사 의견과 실제 수정 자료만 사용하여 대응표와 답변서 초안을 작성하세요.

[편집자와 심사자의 원문 의견]
[수정 전 원고]
[연구자가 실제로 수행한 수정과 추가 분석]
[수정 후 원고의 위치 정보]
[수용하기 어려운 의견과 그 근거]

복합 의견을 하나의 조치로 답할 수 있는 최소 단위로 나누고 고유 번호를 붙이세요.
각 항목에 심사 의견 원문, 쟁점, 대응 결정, 실제 조치, 수정 전·후 문구, 원고 위치,
추가 확인 사항을 기록하세요. 답변은 감사, 의견에 대한 이해, 수행한 조치와 근거,
원고 위치 순서로 간결하게 작성하세요.

실제로 수행하지 않은 분석·실험·수정을 했다고 쓰지 마세요. 의견을 수용하지 않는 경우
방어적으로 표현하지 말고 연구 질문, 자료, 방법 또는 범위에 근거하여 설명하고 가능한
보완책을 제시하세요. 정보가 없으면 "연구자 입력 필요"로 남기세요. 마지막에는 답변이
누락된 의견, 원고와 답변서의 불일치, 편집자 결정과 직접 관련된 항목을 점검하세요.
```

### 제한 조건

- 수행하지 않은 수정이나 분석을 완료했다고 주장하지 않는다.
- 심사 의견의 의미를 약화하거나 일부만 선택해 답하지 않는다.
- 정중함을 위해 과학적으로 동의하지 않는 내용을 수용한 것처럼 쓰지 않는다.

### 검증 체크리스트

- [ ] 모든 편집자·심사자 의견에 고유 번호와 답변이 있는가
- [ ] 답변서의 수정 위치와 실제 원고가 일치하는가
- [ ] 추가 분석의 수치와 결과가 원출력과 일치하는가
- [ ] 수용하지 않은 의견에 명확하고 전문적인 근거가 있는가
