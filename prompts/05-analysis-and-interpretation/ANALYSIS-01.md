# ANALYSIS-01. 분석 전 계획과 의사결정 규칙 작성

| 항목 | 내용 |
|---|---|
| 작업 | 결과를 보기 전에 분석 절차와 분기 기준 명시 |
| 태그 | `분석 계획`, `사전 명세`, `재현성` |
| 입력 유형 | 연구 질문, 설계, 변수·자료 구조, 가정, 결측과 제외 기준 |
| 출력 형식 | 분석 계획표, 의사결정 트리, 재현성 기록 목록 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

분석 결과에 따라 방법을 임의로 바꾸는 위험을 줄이고 재현 가능한 분석 계획을 만든다.

### 필요한 입력

- `[연구 질문과 가설]`
- `[연구 설계와 분석 단위]`
- `[변수 또는 질적 자료의 구조와 정의]`
- `[예정된 분석 방법]`
- `[결측, 이상치와 제외 기준]`
- `[사용할 소프트웨어와 재현성 환경]`

### 프롬프트

```text
결과값을 추측하거나 생성하지 말고, 아래 정보만으로 분석 전 계획을 작성하세요.

[연구 질문과 가설]
[연구 설계와 분석 단위]
[변수 또는 질적 자료의 구조와 정의]
[예정된 분석 방법]
[결측, 이상치와 제외 기준]
[사용할 소프트웨어와 재현성 환경]

연구 질문별 주요 분석, 변수·자료 역할, 전처리, 가정 점검, 제외 기준, 결측 처리,
민감도 분석과 출력물을 표로 연결하세요. 가정이 충족되지 않을 때 사용할 대안과
선택 기준을 의사결정 트리로 작성하세요. 탐색 분석과 확증 분석을 분리하고 다중 비교,
연구자 자유도와 선택적 보고 위험을 점검하세요.

질적 분석이라면 코딩 단위, 코드북 개발, 분석 메모, 불일치 처리, 반례 탐색과 근거
추적 절차를 포함하세요. 필요한 정보가 없으면 방법이나 임계값을 만들지 말고
"확인 필요"로 표시하세요. 마지막에는 실행 전에 고정할 사항과 분석 중 기록할 변경
사항을 구분하세요.
```

### 제한 조건

- 실제 데이터나 결과를 보지 않고 예상 수치를 만들지 않는다.
- 유의한 결과를 얻기 위한 분석 변경을 제안하지 않는다.
- 탐색적 결정과 사전 계획된 결정을 같은 것으로 보고하지 않는다.

### 검증 체크리스트

- [ ] 연구 질문마다 주요 분석과 출력이 연결되었는가
- [ ] 결측·이상치·제외·다중 비교 규칙이 명시되었는가
- [ ] 분석 분기마다 사전에 적용할 판단 기준이 있는가
- [ ] 계획 변경을 기록하고 공개할 방법이 있는가
