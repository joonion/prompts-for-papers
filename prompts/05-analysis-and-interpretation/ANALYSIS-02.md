# ANALYSIS-02. 정량 분석 출력의 근거 기반 해석

| 항목 | 내용 |
|---|---|
| 작업 | 제공된 통계 출력과 설계 범위 안에서 결과 해석 |
| 태그 | `통계 해석`, `효과 크기`, `불확실성` |
| 입력 유형 | 검증된 분석 출력, 변수 정의, 연구 설계, 가정 점검 결과 |
| 출력 형식 | 수치 확인표, 결과 서술, 해석 한계 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

통계적 유의성, 효과의 크기와 불확실성을 구분하여 과장 없이 결과를 서술한다.

### 필요한 입력

- `[연구 질문과 가설]`
- `[연구 설계, 표본과 변수 정의]`
- `[분석 방법과 가정 점검 결과]`
- `[소프트웨어의 검증된 원출력]`
- `[표·그림에 사용할 반올림 및 보고 규칙]`

### 프롬프트

```text
아래에 제공된 통계 출력만 사용하여 결과를 해석하세요.

[연구 질문과 가설]
[연구 설계, 표본과 변수 정의]
[분석 방법과 가정 점검 결과]
[소프트웨어의 검증된 원출력]
[표·그림에 사용할 반올림 및 보고 규칙]

먼저 표본 수, 추정치, 표준오차 또는 신뢰구간, 검정통계량, 자유도, p값과 효과 크기를
원출력에서 그대로 추출한 확인표를 만드세요. 찾을 수 없는 값은 "제공되지 않음"으로
표시하세요. 그다음 연구 질문에 직접 답하는 결과, 효과 방향과 크기, 불확실성,
가정 위반과 민감도 분석을 구분하여 설명하세요.

통계적 유의성과 실제적·임상적 중요성을 구분하고, 비유의 결과를 효과 없음으로
단정하지 마세요. 관찰 연구나 비무작위 설계에서 인과관계를 주장하지 마세요.
새로운 수치, 분석 또는 하위집단 결과를 만들지 마세요. 마지막에는 논문 결과 절에
사용할 객관적 문단과 논의 절에서 다룰 해석·한계를 별도로 작성하세요.
```

### 제한 조건

- 원출력에 없는 수치, 표본 수와 검정 결과를 생성하지 않는다.
- p값만으로 결과의 중요성을 판단하지 않는다.
- 결과 절과 논의 절의 역할을 섞지 않는다.

### 검증 체크리스트

- [ ] 모든 숫자가 원출력과 정확히 일치하는가
- [ ] 효과 크기, 신뢰구간과 가정 점검이 함께 보고되었는가
- [ ] 비유의 결과와 인과관계가 과도하게 해석되지 않았는가
- [ ] 결과 문단과 해석·한계가 분리되었는가
