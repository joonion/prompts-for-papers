# ANALYSIS-03. 결과 표·그림의 정확성과 전달력 점검

| 항목 | 내용 |
|---|---|
| 작업 | 표·그림이 자료와 분석을 왜곡 없이 전달하는지 검토 |
| 태그 | `데이터 시각화`, `표`, `그림`, `캡션` |
| 입력 유형 | 검증된 결과, 표·그림 초안, 변수·단위, 대상 학술지 규정 |
| 출력 형식 | 문제 진단표, 수정 설계안, 캡션 초안 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

논문에 사용할 표와 그림의 정확성, 자급성, 접근성과 과잉해석 위험을 점검한다.

### 필요한 입력

- `[연구 질문과 전달할 핵심 결과]`
- `[검증된 수치 또는 질적 근거]`
- `[표·그림 초안 또는 구조 설명]`
- `[변수 정의, 단위, 표본 수와 불확실성 지표]`
- `[학술지 형식과 접근성 요구사항]`

### 프롬프트

```text
아래 표·그림 초안을 원자료나 검증된 결과의 범위 안에서 점검하세요.

[연구 질문과 전달할 핵심 결과]
[검증된 수치 또는 질적 근거]
[표·그림 초안 또는 구조 설명]
[변수 정의, 단위, 표본 수와 불확실성 지표]
[학술지 형식과 접근성 요구사항]

각 표·그림에 대해 목적, 적합한 표현 유형, 축·단위·범례·표본 수·불확실성 표시,
색상과 접근성, 비교 기준, 중복 정보, 오해 가능성을 검토표로 작성하세요. 축 절단,
면적 왜곡, 이중 축, 선택적 범위, 3차원 효과와 불확실성 생략 여부를 점검하세요.

수치를 새로 계산하거나 만들지 말고, 불일치가 있으면 원자료 확인이 필요한 위치를
표시하세요. 수정된 구조를 텍스트로 설명하고, 결과를 과장하지 않는 제목과 자급적인
캡션 초안을 작성하세요. 캡션에는 대상, 분석, 단위, 오차 표현과 약어 설명을 포함하되
제공되지 않은 정보는 "확인 필요"로 남기세요.
```

### 제한 조건

- 시각적 인상을 강화하기 위해 축이나 표본 범위를 왜곡하지 않는다.
- 검증되지 않은 수치를 계산 결과처럼 제시하지 않는다.
- 색상만으로 집단이나 상태를 구분하지 않는다.

### 검증 체크리스트

- [ ] 표·그림의 모든 값이 검증된 결과와 일치하는가
- [ ] 단위, 표본 수와 불확실성이 명확한가
- [ ] 제목과 캡션이 결과를 넘어선 주장을 하지 않는가
- [ ] 흑백 인쇄와 색각 다양성에서도 구분 가능한가
