# LIT-02. 근거표 작성과 문헌별 정보 추출

| 항목 | 내용 |
|---|---|
| 작업 | 제공된 논문에서 비교 가능한 정보를 근거 위치와 함께 추출 |
| 태그 | `근거표`, `문헌 정리`, `정보 추출` |
| 입력 유형 | 논문 원문 또는 발췌문, 서지정보, 연구 질문 |
| 출력 형식 | 근거표, 누락 정보 목록, 확인 기록 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

여러 문헌을 동일한 기준으로 비교할 수 있도록 핵심 정보를 추출하고 근거 위치를 기록한다.

### 필요한 입력

- `[연구 질문과 검토 목적]`
- `[문헌별 식별자와 서지정보]`
- `[문헌 원문 또는 사용할 발췌문]`
- `[추출하려는 항목]`

### 프롬프트

```text
아래에 제공된 문헌만 사용하여 근거표를 작성하세요.

[연구 질문과 검토 목적]
[문헌별 식별자와 서지정보]
[문헌 원문 또는 사용할 발췌문]
[추출하려는 항목]

문헌별로 연구 목적, 이론적 관점, 표본·자료, 연구 설계, 분석 방법, 핵심 결과,
저자가 밝힌 한계, 연구자가 검토할 한계, 연구 질문과의 관련성을 표로 정리하세요.
각 셀에는 가능한 경우 페이지, 절, 표 또는 그림 번호 등 근거 위치를 함께 기록하세요.

원문에서 찾을 수 없는 정보는 추론하여 채우지 말고 "제공 자료에서 확인 불가"라고
표시하세요. 저자의 명시적 주장과 당신의 해석을 별도 열로 분리하세요. 직접 인용은
짧게 제한하고 정확한 위치를 표시하세요. 마지막에는 원문에서 사람이 다시 확인해야
할 항목과 서지정보 오류 가능성을 문헌별로 나열하세요.
```

### 제한 조건

- 제공되지 않은 논문이나 서지정보를 추가하지 않는다.
- 초록만 제공되었을 때 전체 방법과 한계를 아는 것처럼 작성하지 않는다.
- 저자의 주장과 검토자의 평가를 섞지 않는다.

### 검증 체크리스트

- [ ] 모든 주요 정보에 원문 위치 또는 확인 불가 표시가 있는가
- [ ] 문헌 간 동일한 추출 기준이 적용되었는가
- [ ] 직접 인용이 원문과 정확히 일치하는가
- [ ] DOI, 저자, 연도와 제목을 신뢰할 수 있는 원본에서 다시 확인했는가
