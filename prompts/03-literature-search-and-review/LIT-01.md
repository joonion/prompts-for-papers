# LIT-01. 재현 가능한 문헌 검색 전략 설계

| 항목 | 내용 |
|---|---|
| 작업 | 연구 질문을 검색 개념과 데이터베이스별 검색식으로 변환 |
| 태그 | `문헌 검색`, `Boolean`, `검색 기록` |
| 입력 유형 | 연구 질문, 핵심 개념, 데이터베이스, 범위와 제외 조건 |
| 출력 형식 | 개념표, 검색식 초안, 검색 기록 양식 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

문헌 검색을 재현할 수 있도록 핵심 개념, 동의어, 검색식과 기록 항목을 체계화한다.

### 필요한 입력

- `[연구 질문]`
- `[이미 알고 있는 핵심 용어와 대표 문헌]`
- `[사용할 데이터베이스]`
- `[연도·언어·문헌 유형 범위]`
- `[포함·제외 기준]`

### 프롬프트

```text
다음 연구 질문을 위한 재현 가능한 문헌 검색 전략의 초안을 만드세요.

[연구 질문]
[이미 알고 있는 핵심 용어와 대표 문헌]
[사용할 데이터베이스]
[연도·언어·문헌 유형 범위]
[포함·제외 기준]

1. 연구 질문을 검색 가능한 핵심 개념으로 분해하세요.
2. 개념별 동의어, 철자 변형, 상·하위어와 약어를 표로 정리하세요.
3. 개념 내부는 OR, 개념 사이는 AND를 사용한 기본 검색식을 만드세요.
4. 데이터베이스별 구문 차이를 반영한 검색식 초안을 별도로 제시하세요.
5. 검색일, 데이터베이스, 전체 검색식, 필터, 결과 수를 기록할 양식을 만드세요.
6. 대표 문헌을 이용해 민감도와 정확도를 시험하는 방법을 제안하세요.

제공되지 않은 통제어, 필드 코드나 데이터베이스 문법을 확정적으로 만들지 마세요.
공식 도움말에서 확인해야 하는 표현은 "구문 확인 필요"로 표시하세요. 실제 검색 결과,
논문 수나 최신 동향을 검색하지 않고 추정하지 마세요.
```

### 제한 조건

- 존재 여부를 확인하지 않은 논문이나 데이터베이스 기능을 만들지 않는다.
- 검색 결과 수를 예상값으로 채우지 않는다.
- 검색 범위를 임의로 좁혀 중요한 개념을 누락하지 않는다.

### 검증 체크리스트

- [ ] 연구 질문의 모든 핵심 개념이 검색식에 반영되었는가
- [ ] 동의어와 약어가 중복 없이 개념별로 묶였는가
- [ ] 데이터베이스 공식 문법과 직접 대조했는가
- [ ] 검색 과정 전체를 재현할 기록 항목이 있는가
