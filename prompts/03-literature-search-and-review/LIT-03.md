# LIT-03. 문헌의 비판적 종합과 연구 공백 평가

| 항목 | 내용 |
|---|---|
| 작업 | 제공된 근거표를 비교·종합하고 공백 주장의 강도를 평가 |
| 태그 | `문헌 종합`, `비판적 검토`, `연구 공백` |
| 입력 유형 | 검증된 근거표, 연구 질문, 검토 범위 |
| 출력 형식 | 주제별 종합표, 공백 후보, 서술 개요 |
| 위험도 | 높음 |
| 마지막 검토일 | 2026-08-06 |

### 사용 목적

문헌을 논문별로 나열하지 않고 주제, 방법과 근거의 차이를 중심으로 종합하며 연구 공백을 과장 없이 평가한다.

### 필요한 입력

- `[연구 질문과 검토 범위]`
- `[검증된 문헌 근거표]`
- `[포함·제외 기준과 검색 한계]`
- `[중요하게 볼 이론·방법·대상·맥락]`

### 프롬프트

```text
아래 근거표와 검토 범위만을 사용하여 문헌을 비판적으로 종합하세요.

[연구 질문과 검토 범위]
[검증된 문헌 근거표]
[포함·제외 기준과 검색 한계]
[중요하게 볼 이론·방법·대상·맥락]

먼저 반복되는 주제와 쟁점을 도출하고, 각 주제별로 일치하는 결과, 상충하는 결과,
사용된 방법, 근거의 강점과 한계를 표로 정리하세요. 차이가 표본, 측정, 맥락,
연구 설계 또는 이론적 관점에서 비롯될 가능성을 근거와 함께 분석하세요.

연구 공백 후보를 다음 유형으로 구분하세요: 증거 부족, 대상·맥락 부족, 방법론적 한계,
이론적 불일치, 결과의 모순. 각 후보에 대해 직접 근거, 검색 범위의 한계, 추가 확인이
필요한 문헌을 제시하고 공백 주장의 강도를 강함·잠정적·판단 불가로 표시하세요.
마지막에는 논문별 나열이 아닌 주제별 문헌검토 개요를 작성하세요.

제공되지 않은 문헌이나 사실을 추가하지 말고, "연구된 적이 없다" 같은 전면적 주장은
피하세요. 검색 한계 때문에 생긴 공백과 실제 지식 공백을 구분하세요.
```

### 제한 조건

- 문헌 수가 적다는 사실만으로 연구 공백을 확정하지 않는다.
- 상관관계 연구를 인과 증거처럼 종합하지 않는다.
- 근거가 상충할 때 임의로 한쪽을 정답으로 선택하지 않는다.

### 검증 체크리스트

- [ ] 모든 종합 판단이 근거표의 문헌과 연결되는가
- [ ] 일치·불일치와 방법론적 차이가 함께 분석되었는가
- [ ] 검색 한계와 실제 지식 공백이 구분되었는가
- [ ] 공백 주장의 강도가 근거 수준에 맞는가
