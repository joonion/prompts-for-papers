# 논문 작성을 위한 프롬프트 모음집

논문 작성 전 과정에서 생성형 AI를 안전하고 효과적으로 활용할 수 있도록 돕는 한국어 프롬프트 안내서입니다.

이 프로젝트는 단순히 프롬프트 문장을 나열하는 대신, 연구자가 각 프롬프트의 목적과 한계를 이해하고 결과를 직접 검증할 수 있도록 구성하는 것을 목표로 합니다. 주요 독자는 생성형 AI를 연구와 논문 작성에 활용하려는 대학원생과 연구자입니다.

## 기본 원칙

- 프롬프트는 논문을 대신 작성하기보다 연구자의 사고, 탐색, 검토, 정리와 수정을 지원합니다.
- 학술지 논문과 학위논문에 공통으로 적용할 수 있는 작업을 우선합니다.
- 존재하지 않는 문헌, DOI, 인용, 데이터 또는 통계값을 생성하도록 요구하지 않습니다.
- 연구자가 수행하지 않은 실험이나 분석을 수행한 것처럼 서술하지 않습니다.
- 확인된 사실, AI의 요약과 AI의 추론을 구분합니다.
- 확인할 수 없는 내용은 임의로 보완하지 않고 `확인 필요`로 표시합니다.
- 개인정보, 미공개 연구자료와 민감정보를 불필요하게 입력하지 않습니다.
- 외부 자료를 활용할 때는 원출처와 라이선스를 기록합니다.

## 분류 체계

프롬프트는 학문 분야가 아니라 연구 진행 단계에 따라 분류합니다.

1. 연구 준비와 윤리
2. 연구 주제와 연구 문제
3. 문헌 탐색과 비판적 검토
4. 연구 방법 설계
5. 자료 분석과 결과 해석
6. 논문 구조와 초안 작성
7. 인용, 논증과 문장 검토
8. 투고와 심사 대응
9. 연구 커뮤니케이션

학문 분야와 구체적인 작업 유형은 태그로 관리합니다.

## 프롬프트 구성

각 프롬프트에는 다음 내용을 포함합니다.

- 사용 목적
- 필요한 입력
- 프롬프트 본문
- 출력 형식
- 제한 조건
- 검증 체크리스트
- 출처와 라이선스

작업의 성격에 따라 역할, 평가 기준, 입력과 출력 예시, 후속 프롬프트, 실패 사례와 분야별 주의사항을 추가합니다. 역할 부여는 실제로 작업 품질을 높이는 경우에만 사용합니다.

## 검증 원칙

각 프롬프트는 대표 예시 입력으로 최소 한 번 시험하고 다음 사항을 확인합니다.

- 필요한 입력과 목적이 명확한가
- 요구한 출력 형식과 제한 조건을 지키는가
- 입력이 부족할 때 사실을 임의로 생성하지 않는가
- 허위 출처, 허위 수치 또는 근거 없는 단정을 생성하지 않는가
- 연구자가 결과를 다시 확인할 방법을 제공하는가
- 특정 모델이나 서비스에 불필요하게 종속되지 않는가
- 자연스럽고 명확한 한국어로 작성되었는가

인용과 문헌 관련 결과는 반드시 원문 또는 신뢰할 수 있는 학술 데이터베이스에서 다시 확인해야 합니다.

## 참고 저장소

다음 공개 저장소를 조사 자료로 활용합니다. 외부 프롬프트는 그대로 합치지 않고 중복, 품질, 안전성 및 라이선스를 검토한 뒤 번역하거나 개선합니다.

### University of Basel Prompt Library

University of Basel의 Research and Infrastructure Support에서 공개한 프롬프트 라이브러리입니다. 프롬프트 본문뿐 아니라 목적, 예시, 모델, 버전과 라이선스를 구조화된 메타데이터로 관리한다는 점을 참고합니다.

- [GitHub 저장소](https://github.com/RISE-UNIBAS/prompt-library)
- 라이선스: CC BY 4.0

### ChatGPT Prompts for Academic Writing

연구 주제 탐색, 논문 섹션 작성, 문장 개선과 요약 등 학술 글쓰기 작업을 짧은 프롬프트로 정리한 공개 저장소입니다. 간결한 작업 목록을 만드는 데 참고하되, 허위 참고문헌 생성 위험이 있는 항목은 그대로 사용하지 않습니다.

- [GitHub 저장소](https://github.com/ahmetbersoz/chatgpt-prompts-for-academic-writing)
- 라이선스: 저장소에서 별도 확인 필요

### Awesome Prompts for Academic Work

학문 분야와 언어별로 구성된 학술 프롬프트 모음입니다. 장문 프롬프트의 구조, 분야 태그와 검색 방식을 참고합니다. 분야별 파일에 실제 프롬프트가 없는 경우도 있으므로 저장소의 분류를 완성된 콘텐츠 목록으로 간주하지 않습니다.

- [GitHub 저장소](https://github.com/BevalZ/Awesome-prompt-in-CLI)
- 라이선스: MIT

## 기여 원칙

프롬프트를 추가하거나 수정할 때는 다음 사항을 확인합니다.

1. 기존 프롬프트와 중복되지 않는지 확인합니다.
2. 직접 개발, 번역, 각색 또는 종합 여부를 기록합니다.
3. 원출처, URL과 라이선스를 기록합니다.
4. 위험도가 높은 작업에는 제한 조건과 실패 사례를 추가합니다.
5. 대표 예시로 실행한 뒤 마지막 검증일을 기록합니다.

라이선스가 확인되지 않은 외부 프롬프트는 그대로 복제하지 않습니다.

## 현재 상태

프로젝트의 분류 체계와 작성·검증 원칙을 수립하고 참고 자료를 분석하는 초기 단계입니다. 다음 단계에서는 공통 메타데이터 형식을 정의하고, 각 연구 단계에 필요한 핵심 프롬프트를 선별하여 한국어로 작성합니다.
